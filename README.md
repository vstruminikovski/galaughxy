# Galaughxy — Pixelated Robo-World

A playable slapstick game and real-time machinima studio (React 19 + Three.js / R3F), built touch-first for the Galaxy S25.

- **Pond Life**: a nature mockumentary starring Bog the frog, with the habitat and character sculpted in Blender (`tools/blender`).
- **The Overflowing Kitchen**: a 0.1 micro-voxel sitcom set starring the LED-faced robo.

```bash
npm install
npm run dev        # open the Network URL on your phone (use HTTPS, e.g. Tailscale, for the mic)
```

Controls, architecture and pipeline notes are in [CLAUDE.md](CLAUDE.md).
