# ep01 dialogue

Record each line as `.wav` or `.ogg` with the file name used in `data/episodes/ep01_kitchen_disaster.json`
(for example `01_bear.wav`). Until a clip exists, the line lasts 0.065 s per character of its text.
After adding or re-recording clips, run `python3 tools/sync_audio_manifest.py --check` from the repo root.
